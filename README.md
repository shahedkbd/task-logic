## Features
- **Role-Based Workflows**: Distinct areas and workflows for Worker, Buyer, and Admin roles.
- **Task Management**: Buyers can easily add, update, review, and delete tasks. Workers can see only available tasks with available worker spots.
- **Real-Time Submissions**: Workers submit tasks directly, and Buyers can securely approve or reject submissions, dynamically adjusting rewards.
- **Integrated Payments**: Fully functional demonstration of purchasing site coins integrated with Stripe Payment Elements!
- **Withdrawal System**: Workers can request payouts (20 coins = $1) when they hit the minimum platform limit.
- **Secure Architecture**: Utilizing Firebase Authentication alongside fully hardened custom Firestore Document Rules avoiding any client-side spoofing.
- **Admin Dashboard**: Admin gets an overview of total activities with abilities to modify roles and delete resources safely.
- **Real-Time Notifications**: Integrated Firestore notifications trigger intelligently across submission, approval, rejection, and fund payout events.
- **Responsive Animations**: Framer Motion implementations on the Home page provide an attractive user feel natively.
- **Responsive Design**: Designed Mobile-first leveraging Tailwind responsive layers (sm, md, lg blocks) fitting any viewport size natively.
- **Robust Error Catching**: Unified Firestore Error Catching utility with dynamic logging ensuring any failed validations are monitored efficiently.
